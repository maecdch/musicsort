## ✨ 核心功能亮点

### 🤖 深度 AI 音乐分析
告别繁琐的手动整理！音流脉冲接入强大的 AI 大语言模型 (DeepSeek)，能够深度理解每一首歌曲的元数据（歌名、歌手、专辑等），并自动将其划分为**情绪（如：治愈、燃向）、曲风（如：R&B、电子）、语种或适用场景（如：运动、助眠）**。

### 🚀 灵活的导入方式
无论你处于何种网络环境，都能轻松导入歌单：
- **扫码 / 手机号登录**：最便捷的方式，直接获取并管理你的网易云歌单列表。
- **Cookie 导入**：专为复杂网络环境（如海外服务器部署）设计，稳定可靠。
- **链接解析**：无需登录，直接粘贴公开的网易云歌单链接即可开始分析。

### 📋 零门槛“文本导入”导出法 (推荐)
担心账号安全或 API 限制？我们提供了最通用、最安全的导出方案：
1. **一键复制**：AI 分类完成后，点击卡片上的“复制”图标，即可获取标准格式的歌曲列表文本。
2. **网易云无缝接收**：打开网易云音乐 App 或电脑端，在“我的音乐”中选择 **“导入外部歌单” -> “文本导入”**，粘贴文本，网易云将自动匹配并生成全新歌单！
3. **跨平台迁移**：复制的通用文本格式，完美兼容 [TuneMyMusic](https://www.tunemymusic.com/) 等第三方工具，助你轻松将整理好的歌单迁移至 **Spotify** 或 **Apple Music**。

### 💾 本地数据备份
- **CSV 批量导出**：支持将所有分类结果或单个分类下载为 `.csv` 表格文件，方便你在 Excel 中永久保存或进行二次数据整理。

## 📖 快速使用指南

1. **选择歌单**：通过登录账号选择你的专属歌单，或直接在输入框粘贴任意公开的网易云歌单链接。
2. **启动 AI 分析**：点击“开始 AI 分类”，稍作等待，见证 AI 将数百首歌曲井井有条地归类。
3. **导出与保存**：
    - **方案 A (最稳定)**：点击分类卡片上的“复制”图标，前往网易云音乐使用“文本导入”功能。
    - **方案 B (需登录)**：直接点击“导出到网易云”按钮，通过 API 自动在你的账号下创建新歌单。
    - **方案 C (本地备份)**：点击“下载 CSV”将数据保存到本地电脑。
